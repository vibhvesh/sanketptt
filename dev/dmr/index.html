Why no embedded live audio yet? BrandMeister documents Hoseline as a browser listening service, but does not document a public general-purpose audio API for third-party rebroadcast. Phase 1 therefore links to the official player rather than scraping private endpoints or rebroadcasting traffic without approval. We can add an approved connector after confirming the permitted interface and talkgroup permissions.
Phase 1 is a read-only discovery interface. It does not connect to a DMR repeater or transmit RF. No BrandMeister API key is requested or stored here.
